# Remote Vibe 설치 파일

macOS용 Remote Vibe 설치 파일을 받는 곳입니다.

## 설치

1. [최신 릴리스](https://github.com/ArthurCore/RemoteVibe-releases/releases/latest)에서 `RemoteVibe-v<버전>-macOS.pkg`를 받습니다.
2. 받은 파일을 열어 설치합니다. Apple 공증을 받은 패키지입니다.
3. Remote Vibe를 열면 필요한 macOS 권한을 차례로 안내합니다.

설치한 뒤에는 앱 안의 "업데이트" 단추로 새 버전을 받습니다.
